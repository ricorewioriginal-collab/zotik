# ZOTIK – Die Splitter der Welten

Godot 4 starter project for Build 01: **Lunaris – Der erste Riss**.

## Build 01 Ziel
Ein tatsächlich spielbarer Vertical Slice mit:
- Zotik-Bewegung und Kamera
- erstem sichtbaren Moosling-Gegner
- Echtzeitkampf
- Timeline + Break-Grundsystem
- HP/MP/Stamina
- Inventar, Items und Ausrüstung
- Weltenanker Save/Load
- Mondwald und erster Weltenriss
- Ruinen unter dem Mondwald
- Wurzelkriecher-Miniboss
- Risshüter-Boss
- Lyra als Gastfigur mit einfacher Party-KI
- Dorfangriff und Kapitelabschluss

## Steuerung
WASD = Bewegung | Linksklick/Leertaste = Angriff | F/F12 = Ausweichen | Rechtsklick = Block | Q = Lock-on
