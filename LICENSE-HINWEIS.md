# Lizenzhinweis

Für Quellcode, Spielinhalte und Beiträge ist noch keine Lizenz festgelegt. Bis eine Lizenz ergänzt wird, gelten die jeweiligen gesetzlichen Schutzrechte; eine Nutzung, Weiterverbreitung oder Änderung wird durch dieses Repository nicht pauschal lizenziert.

Vor einer öffentlichen Veröffentlichung müssen eine passende Softwarelizenz sowie getrennte Regeln für Grafiken, Audio, Community-Inhalte und Beiträge festgelegt werden. Keine fremden oder ungeklärten Inhalte einchecken.
