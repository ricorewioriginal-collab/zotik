# Development Contract
- Analyze → implement → test → fix → document → stop.
- No destructive rewrite without evidence and approval.
- Existing configured rules and content IDs override AI improvisation.
- Every persistent object uses stable IDs and schema-versioned saves.
- A feature is not PASSED until its acceptance tests execute successfully.
- Missing final art may use clearly marked placeholders; placeholders are never final.
- Gameplay logic must not depend on a particular visual mesh.
- Content, systems and platform adapters remain separable.
- No unsafe or irreversible data migration.
