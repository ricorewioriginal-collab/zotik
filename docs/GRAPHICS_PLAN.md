# Graphics pass + Android

Owner request (2026-10-02):
- The game should look like Kingdom Hearts / Final Fantasy, not like Minecraft.
- Use the original Zotik references.
- CC0 asset packs are allowed.
- The PC may use the stronger renderer.
- The game must also run on Android.

## Milestones
| ID | Milestone | Content |
|---|---|---|
| G01 | Look & renderer | Forward+ on PC, compatibility renderer on Android/Web; sky, sun, shadows, fog, glow and colour grading per world; CC0 surface textures (Poly Haven); procedural houses, trees, water, crystals; visible area borders with exit gaps |
| G02 | Animated characters | CC0 KayKit rigs (75 animations) for companions/NPCs; Zotik on the shared rig with fox head, ears, tail and scarf from the master sheet palette; animation states for idle/walk/run/attack/hit/dodge/death |
| G03 | Enemies & bosses | stylised enemy models and hit/break VFX |
| G04 | World dressing | CC0 props (KayKit dungeon/medieval packs) placed per area |
| A01 | Android | export preset, touch controls (virtual stick + action buttons), CI APK build |

## Limits (honest)
- A production-quality Zotik model (sculpted, rigged fur, facial expressions) needs either a 3D artist or an image-to-3D tool.
- Uploading the owner's reference sheets to an image-to-3D service was approved by the owner. However, the security policy of this cloud environment blocked it, so it is not done. G02 therefore uses an interim rig model.
- All results remain **placeholders/interim art**, not final production art (CLAUDE.md rule 6).
