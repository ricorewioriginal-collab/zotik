# Lunaris Vertical Slice – Canonical 1.0

## Story flow
Dream/whisper → Zotik home → Mira → Lunaris exploration → Toren/training → Moon Forest → Riftlings → Moon Gate puzzle → Rift Cave → Resonance Bridge → Moonwolf → Weltenanker → Orun → great rift/vision → Weltenklinge → return to Lunaris → Mira/Elwen/Toren reactions → Professorium arrival → Lyra bridge scene/post-climax hook.

## Lyra/Mira continuity
Mira owns the early Lunaris role. She knows local stories and recognizes more about the Weltenklinge/rifts than she initially admits. Lyra remains the wider-world researcher and permanent party character. Lyra's arrival must not invalidate Mira's role; it expands the mystery from local knowledge to Weltenkern research.

## Required playable content
1 main quest; 1 side quest (Sari's lost delivery); combat tutorial; Riftling and Moonwolf; Orun three-phase boss; Moon Gate and Resonance Bridge puzzles with manual reset and hints; persistent chests; shop/inventory/equipment; savepoint; Weltenklinge unique acquisition; character customization persistence; reactive NPC states; Professorium cliffhanger.
