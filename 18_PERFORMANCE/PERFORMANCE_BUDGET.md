# ZOTIK Performance & Size Budget

## Ziel
Basisinstallation möglichst **≤ 2 GB**. Das ist ein verbindliches Planungsziel, keine Garantie vor finaler Asset-/Build-Messung.

## Prinzipien
- Local-First
- Asset-Reuse
- modulare Content-Pakete
- Asset-Streaming
- LOD
- komprimierte Texturen
- Audio-Streaming/Kompression
- dynamisches Laden/Entladen von Regionen
- keine unnötigen Asset-Duplikate
- datengetriebene Welt-/Questdaten

DLC-, Creator- und Event-Inhalte sollen möglichst separat geladen werden. Server speichern keine normalen Spielstände und liefern keine vollständige Spielwelt als dauerhaften Datenstrom.
