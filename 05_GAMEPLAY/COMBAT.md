# COMBAT – WELTENRHYTHMUS

Echtzeitbewegung + sichtbare Timeline.

Aktionen:
- Angriff
- starker Angriff
- Block
- Dodge
- Magie
- Item
- Spezial
- Party-Befehl

Break:
Gegner besitzen Break-Werte. Telegraphierten Angriffe können unterbrochen
werden. Bei vollständigem Break entsteht ein Verwundbarkeitsfenster.

Party:
Maximal 4 aktive Charaktere. Zotik direkt, andere über kontextabhängige AI.

Elemente:
Feuer, Eis, Wasser, Wind, Blitz, Natur, Licht, Schatten, Riss.

Reaktionen:
Feuer + Wind = Flammensturm
Wasser + Blitz = Kettenblitz
Eis + Wind = Schneesturm
Natur + Feuer = Aschebrand
Licht + Schatten = Dämmerbruch
Riss + Element = besondere Rissreaktion
