# DUNGEONS

Allgemeines Muster:
Eingang → Gebiet → Mechanik → Gebiet → Miniboss → neue Fähigkeit/Schlüssel
→ Puzzle → Bossarena → Boss.

Dungeons:
- Ruinen unter dem Mondwald
- Der lebende Wald
- Die vergessenen Kanäle
- Die versunkene Stadt
- Das Weltenarchiv
- Der Ewige Tempel
- Die Vulkanmaschine
- Der Nullkern
- Der Sternentempel
- Finalbereich Elyndra

Puzzlearten:
Licht, Wasser, Feuer, Wind, Zeit, Riss, Charakterfähigkeiten.
